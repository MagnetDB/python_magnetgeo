caisse.

Ces côtes sont données pour une Bitter parfaitement symétrique avec le même nombre de 
disques morts en HP et BP.

Côté de l’ancienne Bitter : 603 mm (sans plateau)

l’est pas). On peut donc soustraire les deux longueurs électriques : 
 
603-602,4=0,6mm que l’on divise /2 pour avoir la différence entre les deux centres magnétiques. 
 
0,6/2=0,3mm de différence entre les deux centres magnétiques vers le bas. (-0,3mm)

dans le même sens :
